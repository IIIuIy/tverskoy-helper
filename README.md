# Tverskoy Helper

Игровой помощник для GTA V RP-проектов: оверлей с поиском по правилам и законам, вики, ИИ-ответами, проверкой RP-ника и списком серверов.
Обновление каждый день!

> **Дисклеймер:** самостоятельный open-source проект. Не связан с какими-либо игровыми проектами, их разработчиками и иными подобными приложениями; все названия игровых проектов принадлежат их владельцам.

## Запуск в разработке

```powershell
npm install     # один раз
npm run dev     # dev-режим с hot-reload
```

## Сборка и проверка

```powershell
npm run build   # собрать out/
npm run smoke   # запустить на 4 секунды для smoke-теста
npm start       # запустить собранное приложение
npm run dist    # NSIS + portable сборки в release/
```

## Режимы работы

- **mock** (по умолчанию, пока `apiBase` пуст): все данные генерируются локально — правила, законы, вики, ИИ-стрим, проверка ника.
- **live**: заполните `apiBase` в `config/app-config.json` (или `%APPDATA%/tverskoy-helper/app-config.json`) — включится HTTP-клиент с контрактом из ТЗ (раздел 4).

## Горячие клавиши

- `Ctrl+Alt+T` (настраивается) — показать/скрыть панель
- `Esc` в поиске — скрыть панель
- `Enter` — отправить запрос

## Структура

```
config/app-config.json   — адреса серверов и проекты
src/main                 — процесс Electron: окна, IPC, бэкенд-клиенты
src/preload              — мост contextBridge (белые списки каналов)
src/renderer             — React UI (панель, ИИ-окно)
src/shared               — общие типы контракта
```
